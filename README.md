# Adquisición de Vivienda VIS/VIP — Simulador Fonvivienda

Simulador interactivo para la proyección de cobertura, presupuesto y cumplimiento de metas en la modalidad urbana de adquisición de vivienda VIS/VIP (**Ministerio de Vivienda, Ciudad y Territorio — Subdirección de Subsidio Familiar de Vivienda**).

## Contenido del repositorio

- `index.html` / `tablero_adquisicion_v2.html`: Aplicación web interactiva (autónoma, sin dependencias externas).
- `Manual_Tablero_Adquisicion_Vivienda.docx`: Manual de usuario en formato Word con capturas de pantalla, explicación de controles, KPIs y fórmulas de cálculo.
